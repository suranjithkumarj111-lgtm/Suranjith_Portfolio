# Suranjith Kumar J - Professional Portfolio

**Senior SDET-2 | AI-Powered QAOps Engineer | 9+ Years Experience**

## Overview

A modern, responsive portfolio website showcasing expertise in Test Automation, AI-Powered QA Testing, CI/CD, Cloud DevOps, and CTV Automation.

## Features

- Dark theme with glassmorphism design
- Animated background particles
- Typewriter effect for roles
- Scroll-triggered animations
- Responsive design (mobile, tablet, desktop)
- Interactive skill bars and counter animations
- Contact form with mailto integration

## Sections

1. **Hero** - Introduction with animated stats and code window
2. **About** - Professional summary and quick facts
3. **Skills** - Technical arsenal with animated progress bars
4. **Experience** - Timeline of professional journey
5. **AI Testing** - AI-powered QA testing capabilities
6. **POC Projects** - Proof of Concepts and innovations
7. **Certifications** - Professional certifications
8. **Awards** - Recognition and achievements
9. **Contact** - Contact information and form

## How to Run

Simply open `index.html` in any modern browser, or use a local server:

```bash
npx live-server --port=3000
```

## Technologies Used

- HTML5
- CSS3 (Glassmorphism, CSS Grid, Flexbox, Animations)
- Vanilla JavaScript (Intersection Observer, Custom Animations)
- Font Awesome Icons
- Google Fonts (Inter, JetBrains Mono)
